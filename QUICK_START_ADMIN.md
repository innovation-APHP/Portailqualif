# Démarrage Rapide - Mode Administrateur

## 🚀 Première connexion

1. **Ouvrez le portail** dans votre navigateur
2. **Cliquez** sur "🔒 Connexion Admin" dans le menu de gauche
3. **Entrez** le mot de passe : `admin123`
4. **Cliquez** sur "Se connecter"

✅ Vous êtes maintenant administrateur !

## 🔐 Changez immédiatement le mot de passe

1. Allez dans **Paramètres** (menu de gauche)
2. Cliquez sur l'onglet **Sécurité**
3. Remplissez le formulaire :
   - Mot de passe actuel : `admin123`
   - Nouveau mot de passe : *votre nouveau mot de passe sécurisé*
   - Confirmation : *retapez le nouveau mot de passe*
4. Cliquez sur **"Modifier le mot de passe"**

⚠️ **Conservez ce mot de passe en lieu sûr !**

## 📱 Gérer les applications

**Paramètres > Applications**

- **Ajouter** : Bouton "+ Ajouter une application"
- **Activer/Désactiver** : Toggle à côté de chaque app
- **Configurer** : Bouton "Modifier" (icône crayon)
- **Supprimer** : Bouton "Supprimer" (icône poubelle)

## 🔌 Configurer une application

1. Cliquez sur le bouton **Modifier** (✏️) d'une application
2. Remplissez les champs :
   - URL de l'instance
   - Clé API / Token
3. Cliquez sur **"Sauvegarder"**

L'application est maintenant connectée ! ✅

## 🗄️ Base de données (optionnel)

**Paramètres > Base de données**

Si vous voulez utiliser PostgreSQL au lieu de localStorage :
1. Configurez votre instance Supabase
2. Entrez l'URL et la clé Anon
3. Activez la base de données

Sinon, laissez désactivé (le portail fonctionne en mode localStorage).

## 🚪 Se déconnecter

Cliquez sur l'icône de sortie (↗) à côté du badge "Administrateur" dans le menu.

Vous revenez en mode lecture seule.
